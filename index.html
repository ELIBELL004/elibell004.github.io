LangGraph PersistentDict — RCE via Unsafe Pickle Deserialization
GitHub Advisory Submitted CVSS 7.8 · High

Unconditional pickle.loads() deserialization in checkpoint/memory/__init__.py allows an attacker who controls a checkpoint file to achieve remote code execution with no authentication required. Distinct from and unreported in all 5 existing LangGraph GHSAs.

smolagents VisitWebpageTool — SSRF via Unvalidated URL
huntr.com Submitted CVSS 8.6 · High

VisitWebpageTool.forward() in smolagents v1.24.0 passes a caller-controlled url parameter directly to requests.get() with no scheme check, no private-IP denylist, and default redirect-following enabled. An attacker who can influence the agent's tool input (e.g. via prompt injection) can route requests to internal cloud metadata services, intranet hosts, or loopback addresses — leaking credentials and instance metadata.

Python SSRF AI/ML smolagents default_tools.py:491
WordPress — Password-Protected Post Content Leak
HackerOne In Triage

Password-protected WordPress posts expose content through an unguarded API endpoint, allowing unauthenticated users to read post body, metadata, and attached media without supplying the post password. Affects a wide range of WordPress deployments relying on built-in password protection as an access control mechanism.
